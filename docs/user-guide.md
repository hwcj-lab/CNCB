# 使用说明

## 启动与导航

按根目录README启动后端和前端，打开 http://localhost:5173/ 。根路由自动进入/tool-recommend，左侧菜单在两个业务页面之间切换。移动窄屏通过左上角菜单打开导航。未知路径有返回入口。

## 数据资源与工具推荐

1. 在DNA序列、蛋白序列、文献数据、物种四个选项中选择类型。
2. 搜索框按数据库英文名或中文名搜索；清空恢复当前类型资源。
3. 点击左侧数据库，右侧只显示该数据库与当前输入类型有调研依据的关系。
4. 点击“查看详情”，核对收录内容、数据类型证据、来源URL与核验日期。数据库没有推荐项时展示明确空态。
5. “访问官方入口”在新窗口打开真实URL；服务介绍、查询接口和分析工具有不同标签。禁用按钮表示访问失败或证据不足，不能据此认为平台已恢复。
6. “兼容性推荐”是本项目建议，不代表数据库原生一键联动。平台不替你上传数据或执行外部工具任务。

“含相关记录”可能只指部分记录；“关联元数据”不表示包含可下载序列；“工具输入支持”指工具接受该类型，不表示此库保存该类序列。DNA甲基化值、变异和蛋白知识不自动当成DNA/蛋白序列。

## 科研产出分析

- 默认“真实样例”：当前只有3条带依据的文献样例，标题等未取得字段留空；顶部和图表注明非全量。
- “合成演示”：仅在后端允许时启用。全部演示文献、机构、人员、基金均标记合成；没有真实PMID/DOI。用于展示完整交互，不能复制为真实成果报告。
- 选择发表年范围和关联数据库，点击“应用筛选”；“重置”恢复2010–2026与全部资源。起始年晚于结束年会提示，后端也会拒绝。
- 年度趋势按论文发表年去重计数，未知年单独报告。折线中空缺年份是当前入库样本的0条，不是中心该年没有论文。
- 环图是资源关联类别多标签统计；一篇论文可进入多类，分类计数之和可超过总文献量，百分比是关联计数的占比。
- 机构只取AUTHOR_AFFILIATION；作者只统计已消歧身份；基金只取PAPER_FUNDING。真实字段未接入时显示“— / 待接入”，不当作0。
- 机构、人员趋势先在下拉框选已可统计对象，再查看年度数量。不能把论文数称为科研能力的全面评价。
- 来源文献表可分页核对模式、PMID/DOI、年份和官方样例链接；合成记录不提供真实文献链接。
- “数据来源”抽屉列官方接口文档与调研验证状态，不代表应用已在线调用全部接口。

## 异常处理

| 现象 | 处理 |
| --- | --- |
| 无法连接服务 | 启动后端，检查8080端口；代理目标与后端端口一致 |
| 无匹配数据库 | 清空关键词或切换数据类型 |
| 图表没有记录 | 调整年份/数据库；查看是否为真实数据缺失，不要期待自动伪造 |
| 合成演示按钮禁用 | MySQL模式默认关闭；仅在独立测试库导入demo-data.sql并启用DEMO_ENABLED |
| 外链禁用/失败 | 查看调研状态与来源，核实后再维护数据库中link_enabled；不要绕过登录或网站限制 |
| 刷新分析页404 | 开发用Vite；部署服务器需SPA回退规则，见开发指南 |

## 如何添加资源和表

已有资源、工具和关系增量维护通常不需要改页面。按[数据库设计](database-design.md)新增目录记录和正确输入关联；新增统计维度或数据表时还需更新Mapper SQL、VO、API文档和前端组件。不要直接修改Vue写入数据库名称或图表数组。
