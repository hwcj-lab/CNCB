# 调研结论到实现的对应关系

日期：2026-11-06。已读取research/README及两个任务目录下的7份文档。实现未修改调研结论；research/README的文件导航按实际新目录修复。

| 调研问题 | 已确认事实/限制 | 当前实现 |
| --- | --- | --- |
| 中心数据库 | 23项重点资源有名称、URL、类型和证据；其他导航未全量核验 | 种子生成器读取数据库表，入库23项；不把合作库和全世界目录算中心自建 |
| 数据类型 | DNA/蛋白的实际序列、元数据、工具输入支持不同；甲基化/变异不是序列 | database_data_type.evidence_role与note保留区别；核心4类+6类辅助类型 |
| 工具 | 32项重点入口，BIT目录148项；计算运行未验证 | 32项原记录全部入库，run_verified=false；另加映射中已有2项文献服务，并明确service_kind |
| 数据库工具关系 | 原生导航与兼容性推荐不同 | database_tool按数据库+工具+输入类型建立关系，保存relation_kind与basis；不将所有同类型工具关联全部数据库 |
| OpenLB | 框架可读，批量文献获取不成功 | 只注册文献检索服务和接入缺口，不编写猜测API |
| cncbbank | 类型、语义、非空语法均未确认 | System状态PENDING；仅预留source_payload原始文本，不给cncbbank定义结构 |
| 官方API | 18个模式有文档；4个示例JSON可读 | source_endpoint注册18项，来源日期/状态保留；不自动调用 |
| 文献样例 | GWH两条、ICG一条有PMID/年份/部分DOI | 初始化仅保存已摘录字段；标题、作者、机构、基金未摘录的留空 |
| 作者机构基金 | 提交机构/资源建设资助与论文署名/资助不同 | 关联角色过滤；真实排名暂为空；缺失显示null与PENDING |
| 研究主题 | 资源关联类别不是学科主题 | 图表称“资源关联类别分布”；分类表可维护，不声称主题模型完成 |
| 七项统计 | 年度与资源类别可做有限样例，身份/基金不足 | 真实有限样例+独立合成展示；所有接口有覆盖率与模式说明 |
| 物种鉴定/构树 | Taxonomy有实际页面，未验证任务结果 | 保留工具入口和说明，不承诺免登录、运行成功、自动预填 |

数据种子由scripts/build-research-seeds.mjs从现有Markdown表读取，避免手抄名称和URL。脚本对23/32/18的基线条数做检查，调研表变化必须评审。分类、输入兼容和关联映射是本项目设计，不是宣称官方已有同名字段。

正式生产初始化没有合成论文、机构、作者、基金。三条真实文献只是调研取样，不是经过全量业务审定的成果集合；GWH项目关联是否为数据使用关系仍未确认。
